# CargonaOS — Enterprise Cargo Management Platform

Современная многопользовательская (Multi-Tenant SaaS) платформа для полной автоматизации карго-компаний и логистических хабов: складской WMS-сканер, рейсы и манифесты, каталог посылок (25,000+ треков), CRM клиентов, пункты выдачи (ПВЗ), кассовый учет, Telegram-бот и личный кабинет клиента (Telegram Mini App).

---

## 🚀 Установка на чистый VPS (в 1 команду)

Для установки на любой чистый сервер (Ubuntu / Debian / AlmaLinux / Rocky / Alpine) выполните одну команду от пользователя `root`:

```bash
curl -fsSL https://raw.githubusercontent.com/SkellyVA/cargona/main/install.sh | bash
```

*Или через `wget`:*
```bash
wget -qO- https://raw.githubusercontent.com/SkellyVA/cargona/main/install.sh | bash
```

### Что сделает установщик автоматически:
1. Проверит и при необходимости сам установит **Docker и Docker Compose**.
2. Создаст рабочую директорию `/opt/cargona` и скачает необходимые файлы платформы.
3. Задаст 4 коротких вопроса:
   * **Домен системы** (например: `prime.akii.world` или `cargo.mysite.com`)
   * **Email Супер-Админа** (например: `admin@cargona.io`)
   * **Пароль Супер-Админа**
   * **Лимит организаций** (`0` для SaaS безлимита или `1` для одной изолированной компании)
4. Автоматически зарегистрирует глобальную консоль **`cargona`** в `/usr/local/bin/cargona`.
5. Скомпилирует и запустит стек сервисов в Docker с автоматическим выпуском **HTTPS SSL-сертификата** (Let's Encrypt / ZeroSSL).

## 🎛️ Глобальное управление через CLI (`cargona`)

После установки команда **`cargona`** доступна глобально из любой папки сервера.

### 1. Интерактивное меню управления:
```bash
cargona
```

Откроется меню с быстрыми действиями:
* **1) Статус:** проверка состояния всех сервисов, лицензии и домена.
* **2) Супер-Админ:** быстрая смена пароля и email администратора.
* **3) Лицензия:** изменение лимита организаций (SaaS безлимит или Single-Tenant).
* **4) Бэкап:** моментальное создание резервной копии базы данных.
* **5) Восстановление:** откат базы из любого ранее сохраненного бэкапа.
* **6) Обновление:** обновление платформы до последней версии с авто-бэкапом перед стартом.
* **7) Перезапуск:** перезапуск всех Docker-контейнеров.
* **8) Смена домена:** мгновенная смена домена с автоматическим перевыпуском SSL.
* **9) Умный импорт:** миграция из MongoDB или JSON-дампов с авто-сбросом кэша.
* **10) Логи:** просмотр системных логов в реальном времени.

---

### 2. Прямые консольные команды:

| Команда | Описание |
| :--- | :--- |
| `cargona status` | Статус контейнеров, лицензии и домена |
| `cargona import --mongo "<URI>" --tenant "<SLUG>" --wipe` | Умный импорт из MongoDB со стиранием старой базы |
| `cargona update` | Безопасное обновление системы с авто-бэкапом |
| `cargona backup` | Создать резервную копию базы данных |
| `cargona backup:restore` | Восстановить базу из резервной копии |
| `cargona admin:reset` | Сменить пароль / email Супер-Админа |
| `cargona limit 1` | Установить лимит: 1 организация (Dedicated) |
| `cargona limit 0` | Установить безлимит организаций (SaaS) |
| `cargona domain new.site.com` | Сменить домен и перевыпустить SSL-сертификат |
| `cargona restart` | Перезапустить сервисы |
| `cargona logs` | Онлайн-просмотр логов всех контейнеров |

## 📥 Миграция и импорт баз данных

CargonaOS оснащена умным движком распознавания схем для бесшовного переноса баз из MongoDB:

```bash
cargona import --mongo "mongodb+srv://user:password@cluster0.mongodb.net/test" --tenant "prime" --wipe
```

**Флаги импорта:**
* `--mongo "<URI>"` — подключение к MongoDB (поддерживаются прямые URI и DNS SRV).
* `--dir "<path>"` — импорт из локальной папки с JSON-файлами.
* `--tenant "<slug>"` — slug организации-получателя данных (например, `prime`).
* `--wipe` — очистить старую базу тенанта перед накатыванием новой (чистая замена).
* `--dry-run` — тестовый прогон без записи изменений на диск.

## 🐳 Управление через Docker Compose

Все сервисы работают в изолированных контейнерах внутри `/opt/cargona`:

```bash
cd /opt/cargona
docker compose up -d           # Запуск контейнеров в фоне
docker compose up -d --build   # Пересборка и запуск с новым кодом
docker compose stop            # Остановка сервисов
docker compose restart         # Перезапуск контейнеров
docker compose logs -f         # Просмотр логов
```

## 🔒 Данные и отказоустойчивость

* Все данные (база организаций, клиенты, трек-коды, финансовые журналы, балансы) хранятся в постоянной директории `/opt/cargona/data/`.
* При перезапусках контейнеров, пересборках или накатывании обновлений **данные никогда не стираются**.
* Перед каждым обновлением через `cargona update` система автоматически создает снапшот базы в `/opt/cargona/data/backups/`.
