# 📦 CargonaOS — Enterprise Cargo Management Platform

Современная модульная платформа для автоматизации карго-компаний: складской WMS-сканер, учет рейсов, CRM клиентов, пункты выдачи (ПВЗ), расчет тарифов, Telegram-бот и личный кабинет клиента (Telegram Mini App).

---

## 🚀 Быстрая установка на сервер (в 1 шаг)

Склонируйте репозиторий и запустите интерактивный установщик:

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> /opt/cargona
cd /opt/cargona
chmod +x install.sh
./install.sh
```

**Что сделает установщик автоматически:**
1. Проверит и при необходимости сам установит Docker и Docker Compose.
2. Спросит ваш домен, пароль Супер-Админа и лимит организаций по лицензии.
3. Автоматически выпустит бесплатный **SSL-сертификат (HTTPS)** через встроенный Caddy.
4. Запустит все сервисы и выведет готовые ссылки для входа.

## 🎛️ Управление сервером через CLI (`cargona`)

В системе установлена удобная консольная утилита. Просто введите команду в любой папке сервера:

```bash
cargona
```

Откроется интерактивное меню:
* **1) 📊 Статус:** просмотр состояния контейнеров и лицензии.
* **2) 🔑 Супер-Админ:** сброс email и пароля администратора.
* **3) 🏢 Лицензия:** изменение лимита организаций (например, `1` для отдельного клиента или `0` для безлимита).
* **4) 💾 Бэкап:** моментальное создание резервной копии базы данных.
* **5) 🔄 Восстановление:** откат базы из любого ранее созданного бэкапа.
* **6) 🚀 Обновление:** безопасное обновление системы с авто-бэкапом перед стартом.
* **7) 🔄 Перезапуск:** перезапуск всех Docker-контейнеров.
* **8) 🌐 Домен:** смена рабочего домена с авто-перевыпуском SSL.
* **9) 📋 Логи:** онлайн-просмотр логов системы.

### Прямые команды для терминала:
```bash
cargona status               # Статус всех контейнеров
cargona admin:reset          # Сменить пароль суперадмина
cargona limit 1              # Установить лимит: 1 организация (Single-Tenant)
cargona limit 0              # Установить безлимит (SaaS)
cargona backup               # Создать резервную копию БД
cargona backup:restore       # Восстановить базу из бэкапа
cargona update               # Безопасно обновить систему
cargona restart              # Перезапустить контейнеры
cargona domain cargo.mysite  # Сменить домен и выпустить SSL
cargona logs                 # Смотреть логи в реальном времени
```

## 🐳 Управление через Docker Compose

```bash
docker compose up -d         # Запустить все контейнеры в фоне
docker compose stop          # Остановить сервисы
docker compose restart       # Перезапустить
docker compose logs -f       # Просмотр логов
```

## 🔒 Данные и безопасность
* Все данные (база организаций, клиенты, посылки, финансовые отчеты) сохраняются на диске в постоянной папке `./data/`.
* При перезапуске, пересборке контейнеров или накатывании обновлений **база данных никогда не стирается**.
