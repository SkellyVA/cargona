# Проверка CLI и меню — 4 октября 2026

Проверки выполнялись на локальных синтетических данных и в CI. Рабочий сервер,
его пакеты, настройки, внешнее хранилище и ключи не изменялись.

## Что исправлено

| Проблема | Исправление |
| --- | --- |
| Подменю печаталось одной плотной строкой, результаты терялись при следующем действии | Отдельный экран, одно действие на строку, группировка и пауза до Enter |
| Отсутствие Restic давало английскую ошибку без дальнейших шагов | Русская инструкция, состояние зависимости в меню, отдельный пункт установки на Debian/Ubuntu с подтверждением |
| Каждая вложенная команда повторно печатала сообщение об установке глобального CLI | Проверяется существующая ссылка; повторное сообщение убрано |
| Ошибки основных действий закрывали меню из-за `set -e` | Действия выполняются отдельным процессом; ошибка сохраняется на экране, меню продолжает работать |
| Статус внешних копий требовал Restic и настроенное хранилище | Статус доступен до настройки; отключение расписания также не зависит от Restic |
| Статусы расписаний падали при отсутствии systemd/таймера | Понятный статус выключенного или недоступного расписания; при включении проверяется зависимость |
| Старый запасной путь бэкапа мог объявить успех без проверенной копии | Используется только проверенный `release.sh`; без него операция завершается ошибкой |
| При отсутствии настройки меню показывало NOOR CLUB включённым | Отображение использует фактическое значение по умолчанию `false` |
| MongoDB URI с паролем был виден при вводе в меню | Ввод скрыт; URI всё ещё может быть виден в аргументах процесса импорта |

Добавлены `cargona doctor` и пункт 19: зависимости, Compose v2, доступность Docker
daemon, Restic и systemd. Проверка ничего не устанавливает и не меняет настройки.
Установка Restic — отдельное действие, требующее root и подтверждения оператора.

## Проверки

- Сборки types, DB, API, web и bot: успешно.
- Полный локальный набор из 26 групп регрессионных тестов: успешно.
- Маршруты меню: внешние копии, мониторинг, миграция, обновление, откат,
  обновление скриптов и репетиция восстановления.
- Ошибка обновления: меню сохраняет управление и позволяет выйти.
- Отсутствие Restic: статус доступен, настройка даёт инструкцию и не создаёт
  частичный файл ключей.
- Установка Restic с двойником apt: отказ не запускает пакетный менеджер;
  подтверждение вызывает update/install; ошибка update запрещает install.
- Бэкапы: неудачная загрузка сохраняет прежнюю отметку успеха, очищает временные
  открытые данные; конфигурация не исполняется как shell-код.
- Мониторинг: повторные одинаковые события не дублируют уведомления;
  неудачная отправка повторяется, восстановление фиксируется.

CI дополнительно выполняет проверки PostgreSQL 16, реальное зашифрованное
восстановление Restic, изолированное восстановление контейнеров и миграцию
JSON → PostgreSQL до публикации образов. Реальная установка пакета apt на сервере
и подключение к пользовательскому B2 требуют запуска оператора; локальные
проверки используют двойники и не выполняют эти действия.
